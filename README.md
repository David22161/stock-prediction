# 📈 Stock Price Prediction Using Machine Learning

## Overview
This project predicts stock prices using machine learning techniques implemented in Python within Jupyter Notebook.

## Objectives
- Load and preprocess stock market data
- Perform exploratory data analysis (EDA)
- Train machine learning models
- Predict future stock prices
- Visualize predictions

- ## Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

- ## Results
The model successfully learned historical stock trends and generated predictions with visual comparisons between actual and predicted prices.
